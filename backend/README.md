# KalaSetu Python Backend API

FastAPI backend engine providing AI Voice Transcription/Extraction, Image Studio Processing (Pillow), Smart Pricing Engine, and Craft Passport services.

## Setup & Execution Instructions

```bash
# Navigate to backend directory
cd c:\Projects\KalaSetu\backend

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn main:app --reload --port 8000
```

Open interactive Swagger documentation in your browser at:  
`http://localhost:8000/docs`
