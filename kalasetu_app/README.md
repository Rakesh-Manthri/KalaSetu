# 🪔 KalaSetu Mobile Application (`kalasetu_app`)

Cross-platform mobile application built with **Flutter 3.x** and **Riverpod** for **Smart India Hackathon 2026** (Problem Statement 26090: *AI-Driven Market Linkage & Smart Cataloging for Marginalized Artisans*).

## Quick Run

```bash
# Install dependencies
flutter pub get

# Launch app
flutter run
```

Please refer to the root [README.md](../README.md) for full project architecture, backend setup, and feature details.
